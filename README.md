
## Como rodar o projeto


```bash
  Primeiramente é necessario ter o node instalado no computador
```

Clone o projeto
```bash
  git clone https://github.com/henriqu3x/biblioteca_simulado_frontend_vf
```

Va para o diretorio do projeto

```bash
  cd my-project
```

Instale as dependencias

```bash
  npm install
```

Inicie o servidor

```bash
  npm run dev
```
